# Improving Dokki documentation

This repository mirrors the [canonical Dokki documentation](https://dokki.one/pub/docs). The README index and documentation pages are generated; direct edits may be overwritten by a later sync.

To report a correction, open an issue here with the canonical page URL, the inaccurate or unclear passage, and a suggested correction or reproducible example. Use synthetic data and remove private workspace details.

Maintainers should update the canonical source and regenerate the mirror. Repository-maintenance changes, such as this contribution guide, can be proposed in a focused pull request.

See the [organization contribution guide](https://github.com/Dokki-lab/.github/blob/main/CONTRIBUTING.md) for general expectations and [support](https://github.com/Dokki-lab/.github/blob/main/SUPPORT.md) for account help. Report vulnerabilities through the [private security route](https://github.com/Dokki-lab/.github/blob/main/SECURITY.md).
